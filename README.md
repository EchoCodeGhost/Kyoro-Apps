# Kyoro Apps

Apps for [Kyoro-HealthHub](https://github.com/EchoCodeGhost/Kyoro-HealthHub), the local-first
health data pipeline: KyoroSymptomTrack, KyoroVitalGuard and KyoroSleepGuard, each planned as a
web (PWA), iOS and Android version.

**Nothing released yet.** Code arrives here once a product has passed a privacy review.

- `dev`: reviewed state, default branch
- `main`: releases
